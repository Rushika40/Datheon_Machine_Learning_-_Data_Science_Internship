# Datheon Machine Learning & Data Science Internship

This repository contains the projects completed as part of the
Datheon Machine Learning and Data Science Internship.

The projects focus on applying machine learning and data science
concepts to practical problems using Python and its popular
machine learning libraries.

## Projects Completed

### Task 1: Iris Classification

**Objective:** Build a machine learning classification model
using the Iris dataset.

**Description:**
- Understand and explore the Iris dataset.
- Perform data preprocessing.
- Build a classification pipeline.
- Train and evaluate classification models.
- Analyze model performance.

### Task 2: NLP Sentiment Classification

**Objective:** Perform sentiment analysis on text data
using Natural Language Processing (NLP).

**Description:**
- Load and explore the sentiment dataset.
- Perform text preprocessing.
- Convert text into numerical features using TF-IDF.
- Classify text into Positive, Negative, and Neutral sentiments.
- Evaluate the classification model.

### Task 3: Real Estate Housing Price Prediction

**Objective:** Predict median house values using the
California Housing dataset.

**Description:**
- Perform Exploratory Data Analysis (EDA).
- Handle missing values.
- Perform feature engineering.
- Apply data standardization and categorical encoding.
- Build OLS, Ridge, and Lasso Regression models.
- Perform hyperparameter tuning using GridSearchCV.
- Evaluate models using RMSE, MAE, and R².
- Visualize predictions and residual errors.
